# Выборы США 2026 — интерактивный дашборд

## Что показывает

- Интерактивную tile-grid карту **50 штатов** (Аляска и Гавайи отдельно).
- Раздельные вкладки **Сенат (35 гонок)**, **Палата представителей (435 округов)**, **губернаторы (36 гонок)**.
- По каждому штату проценты **уже подсчитанных** голосов за демократов и республиканцев, абсолютное число голосов, кандидатов и ссылку на источник, когда они доступны.
- Поиск, фильтр, детальную карточку штата, индикаторы обновления.
- Серые клетки **до появления официально опубликованного подсчёта**. Опросы, досрочное голосование, партийная регистрация и прогнозы **не выдаются** за подсчитанные голоса.

## Данные

Публичный JSON: `https://thepeoplestally.com/data/results.json` (The People's Tally, CC BY 4.0, с атрибуцией исходных источников на странице). Это **неофициальные** данные до сертификации штатами. Загрузка происходит при каждом открытии страницы, при возвращении в активную вкладку (если прошло 30 секунд) и раз в 60 секунд во время просмотра.

При блокировке межсайтовых запросов браузером (CORS) приложение использует локальную копию `data/results.json`. GitHub Action обновляет эту копию во время очередной публикации сайта **примерно каждые 5 минут**. Запуски GitHub Actions могут задерживаться, поэтому время данных показано отдельно; обновление не гарантированно мгновенное.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `us-midterms-2026`, с основной веткой **main**.
2. Загрузите **содержимое** папки `us-midterms-2026` в корень репозитория, **сохранив скрытую папку `.github/workflows/`**. Не загружайте только ZIP как один файл — GitHub должен видеть HTML и workflow.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions**, разрешите выполнение workflows, если требуется, и запустите **Publish election dashboard → Run workflow** (либо отправьте commit в `main`).
5. После успешного деплоя адрес будет вида `https://ВАШ-ЛОГИН.github.io/us-midterms-2026/`. Откройте этот URL в браузере телефона и при желании выберите **Добавить на главный экран**.

**Важно:** публикация из ChatGPT автоматически не выполняется. До выполнения шагов выше у вас нет публичного URL. Просто открытый файл `index.html` на телефоне не гарантирует доступ к данным из-за CORS и ограничений `file://`.

## Проверка интерфейса локально

На компьютере в папке проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. При отсутствии доступа к live-потоку приложение попробует локальный файл `data/results.json` (до первого обновления на GitHub Pages он специально пустой).

## Точность

- **Нет результатов** ≠ **0%**. Вместо нуля показывается прочерк.
- В **Палате представителей** поштатный процент рассчитан по *опубликованным* гонкам в округах штата, а не по завершённому голосованию всего штата.
- Сводная доля партий — лишь сумма уже опубликованных голосов для **выбранного типа выборов** (не общенациональный generic ballot и не число выигранных мест).
- Цвет штата показывает только **лидерство по подсчитанным голосам**, а не окончательную победу.
- Победителя можно считать объявленным только при отдельном официальном/профессиональном решении, а не по текущему преимуществу в процентах.
