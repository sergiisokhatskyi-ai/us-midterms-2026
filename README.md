# Выборы США 2026 — интерактивный дашборд

## Что показывает

- Интерактивную tile-grid карту **50 штатов** (Аляска и Гавайи отдельно).
- Раздельные вкладки **Сенат (35 гонок)**, **Палата представителей (435 округов)**, **губернаторы (36 гонок)**.
- По каждому штату проценты **уже подсчитанных** голосов за демократов и республиканцев, абсолютное число голосов, кандидатов и ссылку на источник, когда они доступны.
- Отдельный блок **досрочного голосования**: количество поданных бюллетеней по штатам и, где доступно, партийную регистрацию избирателей. Это **не** число голосов за кандидатов.
- Поиск, фильтр, детальную карточку штата, индикаторы обновления.
- Серые клетки **до появления официально опубликованного подсчёта**. Опросы, досрочное голосование, партийная регистрация и прогнозы **не выдаются** за подсчитанные голоса.

## Данные

Публичные JSON: `https://thepeoplestally.com/data/results.json` (голоса за кандидатов) и `https://thepeoplestally.com/api/live` (досрочные бюллетени) (The People's Tally, CC BY 4.0, с атрибуцией исходных источников на странице). Это **неофициальные** данные до сертификации штатами. Загрузка происходит при каждом открытии страницы, при возвращении в активную вкладку (если прошло 30 секунд) и раз в 60 секунд во время просмотра.

При блокировке межсайтовых запросов браузером (CORS) приложение использует локальные копии `data/results.json` и `data/live.json`. GitHub Action обновляет эту копию во время очередной публикации сайта **примерно каждые 5 минут**. Запуски GitHub Actions могут задерживаться, поэтому время данных показано отдельно; обновление не гарантированно мгновенное.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `us-midterms-2026`, с основной веткой **main**.
2. Загрузите **содержимое** папки `us-midterms-2026` в корень репозитория, **сохранив скрытую папку `.github/workflows/`**. Не загружайте только ZIP как один файл — GitHub должен видеть HTML и workflow.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions**, разрешите выполнение workflows, если требуется, и запустите **Publish election dashboard → Run workflow** (либо отправьте commit в `main`).
5. После успешного деплоя адрес будет вида `https://ВАШ-ЛОГИН.github.io/us-midterms-2026/`. Откройте этот URL в браузере телефона и при желании выберите **Добавить на главный экран**.

**Текущий сайт опубликован:** https://sergiisokhatskyi-ai.github.io/us-midterms-2026/. Публикация новых коммитов работает через GitHub Actions. Если источник не выдаёт бюллетени или результаты, это отражается в статусе: пустое число не интерпретируется как нулевая поддержка.

## Проверка интерфейса локально

На компьютере в папке проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. При отсутствии доступа к live-потоку приложение попробует локальный файл `data/results.json` (до первого обновления на GitHub Pages он специально пустой).

## Точность

- **Нет результатов** ≠ **0%**. Вместо нуля показывается прочерк.
- В **Палате представителей** поштатный процент рассчитан по *опубликованным* гонкам в округах штата, а не по завершённому голосованию всего штата.
- Сводная доля партий — лишь сумма уже опубликованных голосов для **выбранного типа выборов** (не общенациональный generic ballot и не число выигранных мест).
- Цвет штата показывает только **лидерство по подсчитанным голосам**, а не окончательную победу.
- Победителя можно считать объявленным только при отдельном официальном/профессиональном решении, а не по текущему преимуществу в процентах.

## Версия 2 — Polymarket

Альтернативный адрес новой мобильной страницы: https://sergiisokhatskyi-ai.github.io/us-midterms-2026/live.html

Добавлены рыночные котировки Polymarket: контроль Сената, Палаты представителей, обоих палат и 11 ключевых гонок по штатам. Они загружаются напрямую из публичного Gamma API при открытии страницы и обновляются примерно каждые 3 минуты при активной вкладке. GitHub Actions создаёт резервный снимок `data/polymarket.json` при каждой публикации; при недоступности API показываются доступные данные с отметкой источника/времени, а не вымышленные числа. Отсутствующие котировки отображаются как «нет котировок».

Важное различие: Polymarket — цены контрактов Yes, **не** голоса за партию, не опросы и не официальные результаты. Досрочное голосование показывается отдельно от голосов за кандидатов. Последнее обновление сайта может запаздывать из-за расписания/очереди GitHub Actions.
